Première utilisation sur ce poste

Pour que les boutons ci-dessus fonctionnent, une autorisation doit être donnée une seule fois sur chaque poste : lancez INSTALLER.bat, dans le dossier LAUNCHER du serveur de l'entreprise.

Deux minutes, aucun mot de passe administrateur, aucun logiciel installé. Romain peut vous transmettre le chemin exact.
