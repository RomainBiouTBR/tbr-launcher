Première utilisation sur ce poste

Pour que les boutons ci-dessus fonctionnent, une autorisation doit être donnée une seule fois sur chaque poste : lancez INSTALLER.bat, dans le dossier LAUNCHER du serveur de l'entreprise.

Deux minutes, aucun mot de passe administrateur, aucun logiciel installé. Romain peut vous transmettre le chemin exact.

Les outils se lancent ensuite sur votre poste, avec vos droits habituels, exactement comme par un double-clic. Cette page transmet seulement l'ordre de démarrage : elle ne contient aucune donnée.

Les outils portant la mention Réservé s'adressent à un métier précis et demandent un code au moment du lancement. Si vous devez en utiliser un, demandez le code à Romain.
